# Projects Monorepo

This repo is organized as a collection of independent projects, each in its own subfolder. No need to create a separate repo per project — just add a new folder.

## Projects

- **poker-quiz/** — Poker quiz app
- **SimShampoo/** — SimShampoo project

## Structure

```
projects/
├── poker-quiz/
├── SimShampoo/
└── CLAUDE.md
```

## Adding a New Project

Create a new subfolder for each new project and add it to the list above.
