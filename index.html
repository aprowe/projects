The C¹ curve is a monotone cubic Hermite interpolant (Fritsch–Carlson PCHIP). For each segment we pick tangents so that (1) every marker is hit exactly, (2) the curve never goes backwards (time stays monotonic so video never plays in reverse), and (3) the derivative is continuous at every marker — so the playback-speed plot below has no jumps, unlike the plain piecewise-linear solution.
